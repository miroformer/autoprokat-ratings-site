# Федеральный сайт рейтингов автопрокатов России

## Цель

Витрина и навигация: «топ автопрокатов» по стране и отдельные рейтинги по регионам. Не место, где заново придумывают методику скоринга.

## Регионы

Калининград — первый. Следующие — только по факту опубликованного среза.

## Связь со скорингом

Живой скоринг и методика живут в другом Project. Сюда попадают только опубликованные срезы, когда их даст владелец. Пока среза нет — каркас и договорённости, не фейковые топы. Витрина рейтинги не считает.

## Издатель

ООО «Рентпрог».

## Принятые решения

- Один хост, папки регионов (не поддомены).
- Папку региона не открывать без хотя бы одного опубликованного типа. URL типа — только после среза этого типа. `/kaliningrad/` как рейтинг — только после research; до свода — хаб без таблицы.
- Срез примерно раз в год; текущий виден до нового; предыдущий — в архиве.
- Канал: органика. Баннер — неширокая строка сверху (стандартный минимум РСЯ + оповещения); не путать с таблицей рейтинга. Пока слот пустой — **не рендерить**. Точный размер открыт.
- Юридические оговорки для таблицы без платных мест — утверждены владельцем. Места в таблице не продаются.
- Источник рейтингов — **0а**: три готовых среза из скоринг-проекта (запросы / отзовики / исследование). Считать запросы и отзовики на витрине нельзя.
- Корень сайта — **оглавление** без федерального топа. Федеральный топ — только после федерального среза.
- Директ льётся на **тот же URL**, что органика. Отдельного `/direct/` нет. На странице рейтинга первый экран = топ-3. На хабе топ-3 нет.
- «Все» = **участники среза**, не исчерпывающий рынок. Без брендовых запросов за год в срез не входят (правило методики скоринг-проекта; витрина это не считает).
- **Сетка.** После среза исследования канон `/kaliningrad/` = рейтинг-исследование; топ-3/5/10/полный список — разделы одной страницы; кнопки топ-3/5/10 = якоря, не новые URL. `/zaprosy/` и `/otzyvy/` — доп. рейтинги с той же схемой и теми же кнопками топ-3/5/10. До исследования `/kaliningrad/` — хаб без таблицы мест (описание и ссылки, без мест и баллов); URL не занимать другим рейтингом. Кнопки топ-N на хабе — только когда там появится research; пока на хабе нет. Живые рейтинги — zaprosy и otzyvy. 4-го сводного нет. Отдельных URL топ-3/5/10 нет. Слаги в примерах — латиница. В JSON ключа `tables.research` нет, пока свод не готов.
- **Строка среза.** В каждой таблице: `company_id` (стабильный kebab), `name`, `place` (место в этой таблице), `score` (число или `null`, если свод не готов). В новых пакетах не `id`/`rank`. Плюсы/минусы — опциональный `card` на строке (`pros`/`cons`); обычно research; нет текста — поля `card` нет; пустые карточки и пустые массивы не отдаём.
- **Архив.** В индексе — полная страница среза на дату. Архивные обрезки топ-3/5/10 не заводить.
- **Методика.** Кратко на странице рейтинга + одна `/metodika/` на все регионы. Детали региона (дата / охват / версия) — на странице рейтинга. Формула — на методике, в регион не копировать.
- **Карточки.** Описания у топ-10, не у всего списка. Текст плюсов/минусов — из `card` строки среза (обычно исследование). Карточка только на странице рейтинга.
- **Подача страницы рейтинга.** Топ-3 с баллом → короткий блок доверия → карточки топ-10 из исследования → дальше полный список таблицей. Кнопки топ-3/5/10 — якоря на странице рейтинга; на zaprosy и otzyvy одинаковые; на хабе их нет, пока нет research.
- **Дизайн.** Принят визуальный микс: токены «Честного кубка» (цвет, pill-кнопки, форма блоков, значки) + структура витрины. Образец: [design-sample.md](design-sample.md). Не база «всё с кубка»: не табло премий, не чужой контент, не IA кубка. Сетка — витрины: хаб без мест, живые zaprosy/otzyvy, подача топ-3→доверие→карточки→таблица. Сравни — референс подачи comparison, не палитра: [sravni-dark.png](../media/references/sravni-dark.png). Баннер-слот: пока пустой — не рендерить. Макеты и вёрстку не стартовать без JSON-пакета среза. Код, страницы, баллы не делать.
- **SEO-дополнение.** Только упаковка фактов среза (заголовок, лид, перефраз). Запрещено: новые плюсы, цифры, отзывы, места, шаблон «лучший прокат в {город}». Нет текста в срезе — нет карточки, только строка таблицы.
- **Отдельных URL компаний нет.** `/kaliningrad/{company}/` и аналоги не создавать.
- **Статика из файла среза, не SPA.** Страница рейтинга — статический HTML из файла опубликованного среза. Новый срез → пересборка HTML + архив предыдущего. Не клиентское SPA. Живой скоринг на витрине нет. Стек сейчас не выбирать. Агент должен уметь дорабатывать и обновлять рейтинги.
- **Прод-хост: Yandex Object Storage, режим Hosting.** GitHub Pages — превью, не прод. Домены остаются на REG.RU (DNS на бакет). REG.RU shared и webhost1 не выбраны. Решение принято; внедрение ждёт аккаунт Yandex Cloud и имя домена. Имя домена и ID облака не выдумывать. Ничего не покупать, не деплоить, бакет не создавать. Подробности: [hosting.md](hosting.md).

## Открыто (предложения, не внедрение)

Подробности: [структура витрины](site-structure.md), [контракт среза](snapshot-contract.md), [ветки](workstreams.md), [образец](design-sample.md). Дальше — по 1–3 вопроса за раз. Стек не выбирать. Код, страницы, макеты и баллы не делать. Вёрстку не стартовать.

**Итоговый срез исследования ещё не собран.** `wordstat` и `reviews` готовы в скоринге. Схема строки принята. Хаб `/kaliningrad/` без таблицы мест принят; в пакете ключа `tables.research` нет до свода. Мест и баллов здесь нет.

**Микс принят:** токены кубка + IA витрины. Баннер-слот пока пустой — не рендерить. **Ждём package JSON от рейтинга.** Без пакета вёрстку не стартовать. Не внедрять. Точный размер баннера открыт — [структура витрины](site-structure.md) §11.

**Референсы — идут.** Хостинг: решение принято (Yandex Object Storage Hosting), внедрение не начато — ждёт аккаунт Cloud и имя домена. Сборка, SEO-шаблоны, счётчики, баннер-креатив — нет.

## Жёсткие правила

- Прежде чем писать код, вёрстку, структуру репо, стек, дизайн-систему или контент — исследование практик, затем вопрос владельцу.
- Без «ок» не внедрять стек, сетку страниц, визуал, CMS, доменную схему, SEO-шаблоны.
- Нет данных или решения — сказать. Не выдумывать баллы, парки, отзывы и места в таблице.
- Крупные развилки — сначала обсуждение.

## Не делать

- Пересбор весов и блоков рейтинга Калининграда
- Скоринг компаний «на глаз»
- Продажа мест в таблице
- Отдельные индексируемые URL топ-3 / топ-5 / топ-10 одного среза
- Архивные обрезки топ-3 / топ-5 / топ-10
- Четвёртый «сводный №1» средним трёх мест
- Отдельные URL компаний
- SEO-текст сверх фактов среза
