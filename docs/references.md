## Что рекомендовать дизайну (без макета)

Не внедрять. Это список паттернов под уже принятую подачу.

1. **Первый экран (мобильный = основной).** Три строки/карточки: место, имя, балл среза. Не пьедестал с кубками. Не три колонки, которые не помещаются в 320–390px. Баннер — неширокая строка **над** этим блоком (минимум РСЯ + оповещения), без заглушки «здесь реклама»; можно скрыть полностью. Точный размер открыт.
2. **Сразу под тройкой — доверие, не лид SEO.** Компактный блок: издатель (ООО «Рентпрог»), дата среза, охват («участники среза, не весь рынок»), версия, ссылка «как считали» на `/metodika/`. Формулы в блоке нет. Образец плотности — шапка Сравни (дата в заголовке) + ссылки Банки.ру (методика/правила), не Q&A.
3. **Карточки только топ-10 и только из текста среза.** Плюс/минус — поля среза, не домысел. Нет текста в срезе — нет карточки, только строка таблицы (принято). Не номинация «самый удобный график» на каждую строку (анти-паттерн Марки качества). Не отдельные URL компаний.
4. **Дальше — HTML-таблица полного списка.** Колонки из среза: место, имя, балл, ключевые поля. Дефолтная сортировка = место этого рейтинга, не алфавит. Липкое имя слева; горизонтальный скролл **таблицы**, не страницы (конфликт с проверками Яндекса — не прятать таблицу на мобильном и не раздувать её в 12 колонок). NN/g: сравнение устойчиво при ≤5; топ-3 — сравнение, полный список — скан.
5. **Оговорки у таблицы**, не только в подвале: не реклама, места не продаются, срез на дату, не оферта. Строку участника за оплату не подсвечивать. Баннер, если появится позже — другой контур, с маркировкой.
6. **Балл среза ≠ звёзды отзывов.** Не рисовать 4.9★ и не размечать `AggregateRating`. Визуал балла — число среза (как RAEX / Comparees / CR «N/100»), с указанием шкалы на методике.
