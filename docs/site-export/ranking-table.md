# Рейтинг по картам и отзывам

Срез 26 сентября 2026. Калининград, суточный автопрокат.

**Это не сводный рейтинг из пяти блоков.** Ниже — опубликованный рейтинг репутации на картах. Индекс \(I\) считаем по текущим оценкам и числу отзывов на Яндекс Картах, Google Maps и 2ГИС; на витрине балл = \(20\times I\) (то есть \(I/5\times 100\)), шкала 0–100, один знак после запятой. Места и баллы других блоков (поиск, сервис, защита, парк, география) сюда не смешаны.

Вне таблицы: каршеринг Яндекс Драйв, Делимобиль, Сити рент каршеринг и Белка кар (BelkaCar); Лайф рент и Литл рент; компании без карточек ни на одной из трёх площадок. Офис Амбер кар в Зеленоградске и любые карточки Сити рент в Храброво в индекс не входят.
