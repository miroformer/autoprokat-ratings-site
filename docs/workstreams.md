# Ветки и сборка витрины

Дата: 26 сентября 2026. Стек не выбирать. Дизайн, сборку, SEO-шаблоны, счётчики и баннер не стартовать. Контракт среза не стартовать.

Опора: [контекст](project-context.md), [структура](site-structure.md).

## Принято

Сетка, архив, методика, карточки топ-10 на странице рейтинга, SEO-граница (только факты среза), отдельных URL компаний нет. Калининград — первый регион.

**Статика из файла среза, не SPA.** Страница рейтинга — статический HTML из файла опубликованного среза. Новый срез → пересборка HTML + архив предыдущего. Живой скоринг на витрине нет. Стек (генератор, фреймворк) сейчас не выбирать. Агент должен уметь дорабатывать и обновлять рейтинги.

**Карта потоков** — таблица ниже, включая «подбор оптимального хостинга».

## Карта работ (принято)

Порядок. Идут референсы и хостинг. Контракт на витрине не начинать. Баннер не в старте.

| # | Поток | Когда | Что |
|---|---|---|---|
| 1 | Референсы | идёт | подбор витрин/рейтингов для визуала и подачи; не копировать чужие топы |
| 2 | Контракт среза | ждёт формат от скоринг-агента | поля и формат файла среза; импорт из скоринг-проекта. Владелец передаёт черновик ТЗ скоринг-агенту |
| 3 | Дизайн | после референсов | визуал страниц по принятой сетке |
| 4 | Сборка + техника | после ок на стек | HTML из среза, архив, robots, sitemap |
| 5 | SEO-шаблоны | после контракта полей | title/H1/лид только из фактов среза |
| 6 | Счётчики | когда будет URL | метрики на живой хост |
| 7 | Баннер | позже | слот уже заложен; креатив не стартовать |
| 8 | Хостинг | идёт | подбор хоста под статическую витрину; стек не выбирать |

Не отдельные потоки, а внутри 4/5: robots, sitemap. Перенос рейтингов из скоринг-проекта = поток 2, не отдельная ветка «скопировать сайт».

**Субагенты по регионам — нет.** Срезов других регионов нет. Один шаблон региона; Калининград первый. Следующий регион — только по факту среза.

Ветки в git не открывать.

## Черновик ТЗ владельцу: минимум к передаче данных

Не внедрение. Не контракт на витрине. Черновик, чтобы владелец передал скоринг-агенту (другой Project).

- Формат: JSON.
- Пакет на дату (один опубликованный срез = один пакет).
- Поля: id, имя, место, балл, тексты топ-10, дата, версия методики.
- Стабильный id между годами (одна компания — тот же id в новом срезе и в архиве).
- Нет текста у карточки топ-10: карточки нет, только строка таблицы (уже принято в SEO-границе).

Черновик ТЗ владелец передаёт скоринг-агенту. Новых вопросов в этом файле нет.
